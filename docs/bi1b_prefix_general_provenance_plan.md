## Mission

Extend the source-first provenance extraction (v6 class: proved
families and theorem-impossibilities, zero residuals) from the enacted
prefix to the three alternate Stage-4 prefixes, Stage-8 window first;
resolve every candidate in each branch's Stage-8 cone to
`ProvedFamily` or theorem-impossibility; resume the discharger census;
iterate window by window as branches advance, to each branch's
debt-free halt or lawful stop.

**The central discipline: bytes are not provenance.** That `e01de7…`
is byte-identical to the enacted Stage-8 winner licenses *nothing*:
semantic families are prefix-relative, and the enacted classification
may not be imported, copied, or used as a prior. Each prefix re-derives
provenance from the candidate and its own sealed prefix alone. The
byte-identity is recorded as a zero-charge diagnostic (see BI-1b-D)
and is evidence only for later UC-1 scoring, never a shortcut here.

## Tasks

- **BI-1b-0 (regression rung — hard gate).** Run the prefix-parametric
  extraction on the *enacted* prefix's Stage-8 window first. It must
  reproduce the v6 classifications exactly — same families, same
  impossibilities, zero residuals. Failure → all BI-1b output void;
  fix the machinery, never the corpus (F-BI5 pattern).
- **BI-1b-1 (Stage-8 windows).** For each alternate prefix: enumerate
  nothing new (the cones are sealed); classify every cone candidate by
  the same parametric issuer — proved family with anchor relation, or
  theorem-backed impossibility. Zero residuals per window; any
  candidate the theorems cannot classify is a named gap and that
  branch's stop stands.
- **BI-1b-2 (resumed census).** Where a window reaches zero residuals,
  rerun the discharger census under adopted law: exactly one typed
  total discharger → the branch advances and the next window opens;
  multiple admissible dischargers → the branch stops for the tie
  ladder (R-T1 quotient → R-T2 confluence → R-T3 to the adopter;
  semantic ν may NOT break the tie — Option A, permanent); zero
  dischargers → the Stage-8 deadlock taxonomy applies and the state is
  that branch's sealed terminus (a G4 verdict, not a failure).
- **BI-1b-3 (iterate to halt).** Repeat classification + census per
  stage per branch until debt-free halt (O = ∅ at the branch's own
  final stage) or lawful stop. Per-stage outputs as in the BI-1 plan:
  live demand, cone size, discharger count, winner digest, (κ,
  semantic ν — diagnostic), disposition.
- **BI-1b-D (byte-correspondence diagnostic).** Per stage, record
  which alternate-branch cone candidates and winners are byte-identical
  to enacted counterparts, and which differ only through Stage-4
  references (the fork-shadow relabeling). Zero charge, no selector
  role; this is UC-1 P2/P3's raw material, sealed for later scoring.

## Pre-registered stop and outcome semantics

- **Expressivity gap.** A classification requiring semantics beyond
  the adopted closure, dependent-context, comprehension, and
  provenance rules → named gap, versioned adjudication, no
  improvisation (standing pattern).
- **Divergence is a result.** An alternate branch selecting a
  different winner, exporting a different demand, or halting at a
  different stage than the enacted branch → published verbatim,
  branch continues on its own history; nothing is repaired (F-BI3).
- **Completion.** A branch reaching debt-free halt becomes eligible
  for its BI-2 finale (per the BI-1 plan); all four branches disposed
  (halt or sealed terminus) makes BI-4 assemblable. BI-1b itself
  issues no BI-4 verdict, no G2/G3 comparison, no UC-1 scoring, and no
  unindexed claim.

  all BI-1b artifacts void.
- **F-B1b-2.** More than one extraction procedure digest across
  branches, or any parameter varied per prefix → void; one parametric
  issuer, replayed everywhere.
- **F-B1b-3.** Any census counting an `Unknown` or residual candidate,
  in either direction (as discharger or as excluded) → void; census
  runs only over fully classified cones.
- **F-B1b-4.** Any enacted classification, family ID, or outcome
  consumed by an alternate-branch derivation → that branch's run void
  (F-BI1 verbatim).
- **F-B1b-5.** Byte-identity used as provenance, prior, or selector →
  void; the diagnostic ledger is write-only until BI-4/UC-1.
- **F-B1b-6.** Any tie broken by value, bar, order, or hash → invalid
  on its face (F-S4-3, F-RT3); ties stop branches, period.
