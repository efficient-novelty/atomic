## Result

V3 corrects the authority order in two places:

1. semantic-family identity is derived from structural event/declaration
   support, not demand provenance; and
2. the first rewrite theorem may use the positively verified empty historical
   base instead of waiting for a theorem about an arbitrary nonempty
   predecessor.

This correction removes nonempty demand-orbit and demand-realization authority
from the seed, native-carrier, rewrite-system, and Q0 critical path. Demand
authority remains mandatory downstream, after family quotienting, weakening,
and marginal-family identification, before SR2 may credit a family with an old
demand.

The prototype implements a demand-neutral V3 seed base, an isolated
proof-carrying synthesis successor, and a safe-Agda abstract dependent-typing
foundation. It also demonstrates synthesis-backed binder-local traversal for
fixed supplied roots. It then halts before a native V3 carrier and complete
occurrence census because the full production typing-and-synthesis metatheory
is still unminted.

The mirror algorithm is not trusted. It verifies the supplied dependent

In particular:

The capability and derivation nodes have private fields and no deserialization
path. The synthesis crate is not a new trusted kernel, does not expose the
private `pen-kernel` inference function, and grants no Profile A authority.

## Positive fixed-root occurrence evidence

The V3 occurrence traversal can use the isolated synthesis capability for a
fixed caller-supplied root. For such a root it:

- reconstructs each exact binder-local context;
- synthesizes focused terms, including a variable in function position;
- checks the synthesized type with the unchanged kernel;
- retains the full opaque `VerifiedSynthesizedJudgmentV1` capability for each
  occurrence and binds its digest together with an independent kernel replay;
  and
- fails closed on type mismatch, outside-fragment syntax, or resource
  exhaustion.

The variable-headed application fixture closes the concrete technical gap
that caused the V2 traversal to return `MissingTypedOccurrenceCensus`.

This is not a complete census authority. An arbitrary caller-supplied root
slice, including an empty slice, does not prove that every carrier-derived
root was supplied. Until the production typing correspondence and native V3
carrier provide the authoritative finite root domain and complete coverage
proof, the public gate must remain:

```text
Unknown(MissingSynthesisBackedTypedOccurrenceCensus)
```

Fixed-root traversal evidence is therefore not promoted to rewrite, overlap,
or Q0 authority.

## Exact production typing frontier

The requested `VerifiedLambdaUnitTypingMetatheoryV1` has private fields, no
deserialization path, and no constructor reachable from the current verifier.
It remains unminted despite the positive synthesis implementation and
safe-Agda foundation.

Exactly four correspondence theorems remain:

1. **Oldest-first finite de Bruijn contexts.** The Agda calculus uses an
   abstract variable set and context assignment. It has not been related to
   `DependentContext`'s oldest-first finite vector, exact index convention,
   lookup distance, shift, and binder extension.
2. **Kernel conversion and normalization.** Agda synthesis completeness is
   proved for the conversion-free declarative relation. It has not been shown
   complete for the unchanged kernel's definitional equality, normalization,
   and checked conversion behavior.
3. **Rust synthesis term and derivation codes.** No erasure/correspondence
   theorem yet identifies Agda terms and synthesis derivations with the exact
   `pen-kernel` terms and `pen-kernel-synthesis` rule-coded proof trees.
4. **Exact typed Q0 and family inventories.** The abstract typed reduction
   and raw family-naturality theorems have not been connected to every exact
   V3 Q0 schema and registered semantic-family constructor.

The full diagnostic therefore returns:

```text
Unknown(MissingLambdaUnitTypingMetatheory)
```

Computing and binding manifest, kernel, synthesis, typing, substitution, Q0,
family, Agda source-tree, and checker-transcript digests does not replace any
of these correspondence proofs.
