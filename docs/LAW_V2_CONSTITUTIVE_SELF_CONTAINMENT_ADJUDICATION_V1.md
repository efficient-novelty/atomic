# Law V2 constitutive self-containment adjudication V1

**Date:** 2026-07-29

**Status:** `DRAFT_PROPOSED_NOT_ADOPTED`

**Proposed profile:** `gsc-contextual-internalization-v1`

## Authority boundary

This document is a research proposal, not a semantic manifest. It has no
semantic digest, grants no production rule, and authorizes no registered-H3
run. Profile A remains the frozen owner-specific negative control.

The proposal deliberately uses no archived candidate hash, multiplicity,
later Genesis structure, physical name, desired continuation depth, or
historical novelty total.

## Constitutive motivation

The Constitutive Law treats coherence as relational: every admission creates
definite, checkable incompletenesses. The ambient calculus and verifier process
public judgments using formation, substitution, reindexing, and comparison.
If one of those operations has acted nontrivially on sealed public content but
remains permanently available only in that external metalanguage, part of the
public world's indispensable logical work has no public account.

This V1 hypothesis is deliberately scoped to projection-induced reindexing.
Other indispensable operations, including general substitution or comparison
not represented by such a projection, remain `OutsideFragment` for this
profile rather than triggering an improvised analogue.

The proposed clause is:

> **Constitutive Self-Containment.** Once a verified public context extension
> has induced a nontrivial reindexing action on sealed public structure, the
> Constitutive Law issues an obligation to expose the least
> presentation-invariant universal public interfaces that account for that
> action.

“Least” means universal uniqueness up to the adopted equivalence. It does not
mean fewest clauses, lowest cost, best score, or a preferred search result.

The older PEN paper's adjoint-triple discussion supplies mathematical
motivation for looking at both universal directions around reindexing. It is
not a production certificate. The coherence-depth result is also narrower
than this hypothesis: it explicitly does not claim that all sealed library
growth is foundational or globally acting. Self-containment therefore needs
its own generic trigger and falsification program.

## Trigger

No obligation is emitted merely because a context exists. A trigger requires
one verified frame containing:

- a verified base context \(\Gamma\);
- a verified genuine public extension \(\Gamma.A\);
- its verified projection \(\pi:\Gamma.A\to\Gamma\);
- the checked reindexing action \(\pi^\ast\);
- a sealed public judgment on which that action has actually operated;
- authenticated birth and type support; and
- a presentation-invariant proof that the action is nontrivial.

Identity reindexing, irrelevant weakening, an unused prior declaration, and an
action already eliminated by a proved weakening/erasure equivalence do not
trigger. If the required universal interface is already publicly derivable,
the corresponding port is recorded `Derived` and no duplicate debt is issued.
Failure to decide the frame, action, nontriviality, or prior derivability
returns `OutsideFragment`, `ResourceExhausted`, or `Unknown` as appropriate;
it never creates a positive obligation by default.

The present frozen GSC compiler has only an identity `context_map` grammar and
always records `IdentityV1`. That reserved field is an interface seam, not
evidence of a nontrivial reindexing action. Profile A therefore does not prove
that this proposal's trigger fires. A successor must implement and verify
genuine context projections and nonidentity reindexing on generic sealed
content before the hypothesis can be tested.

## Anonymous universal output

For a triggered projection, the proposed demand names no familiar type former.
It asks for universal completions of the reindexing operation itself.

For `LeftOfReindexing`, construct an operation \(L\), unit, counit, natural
hom-equivalence, both triangle identities, and substitution-stability proof
certifying

\[
L \dashv \pi^\ast .
\]

For `RightOfReindexing`, construct an operation \(R\), unit, counit, natural
hom-equivalence, both triangle identities, and substitution-stability proof
certifying

\[
\pi^\ast \dashv R .
\]

Each direction must also prove typing, naturality, presentation invariance,
demand-connectedness, compatibility with existing obligations, and exact free
sealing. A symbol, package label, or selected family of instances is not a
universal completion.

Payment must expose a fresh public operation or identify a previously public
operation with the demanded interface by a replayed universal-property
certificate. A verifier-side construction that remains available only in the
ambient metalanguage is not payment. The demand census must expire an
already-public certified completion instead of resealing it.

The two polarities are obligation kinds, not two expected historical
candidates. If several inequivalent complete responses survive the full
quotient, the result is the full cone.

### Draft decision

The proposed profile should require

\[
L\dashv\pi^\ast\dashv R.
\]

This is a draft decision, not an adopted law or a deduction from
polarity-neutrality alone. Symmetry supplies an abductive reason to test both
directions, while selecting only one side would require a further
polarity-specific constitutive premise. A one-sided interface may exist in a
particular fragment; that fact is a required test of the proposal, not
permission to silently weaken the two-sided obligation after seeing a result.

If independent review finds a genuine constitutive asymmetry, it should define
a separately named one-sided profile before any live run.

## Preservation of local completion

Contextual internalization extends rather than replaces the existing
constitutive grammar. `G-Use` and `G-Compute` remain registered demand kinds.

A contextual response is complete only if it either:

1. derives the exact owner-specific eliminator and its constructor computation
   rule from the universal package; or
2. includes those local outputs in the same demand-connected total response.

It may not evade, weaken, relabel, or silently replace the local computation
equation. Universal interfaces that leave either local port unpaid are not
total dischargers.

## Generic pre-freeze tests

The profile must be developed without the registered Genesis prefix and must
pass matching Rust and Agda vectors for:

1. a context extension with two nullary constructors;
2. a nonrecursive constructor with an argument;
3. a genuinely dependent family;
4. equivalent presentations of one projection;
5. an irrelevant prior declaration;
6. no nontrivial context extension;
7. a fragment in which only one adjoint direction exists; and
8. inconsistent or unsupported proposed universal equations;
9. a completion constructible only in the verifier's ambient metalanguage;
10. an equivalent universal completion already certified as public; and
11. a non-projection substitution or comparison.

The suite must additionally check identifier permutation, naturality,
substitution stability, both triangle identities, full-quotient invariance,
local-eliminator specialization, total local discharge, and exact free
sealing.

Expected fail-closed behavior is part of the suite. In particular, a
one-sided-only case does not satisfy the proposed two-sided demand; an
unsupported universal equation is not accepted because it resembles a
desired interface; a verifier-only construction is not payment; an
already-public completion is `Derived` without resealing; and a non-projection
operation is `OutsideFragment` in V1.

## Explicit falsifiers

The proposal is rejected or returned for readjudication if any of the
following occurs:

- the trigger depends on a registered-prefix identity or fires on identity or
  irrelevant weakening;
- a non-projection substitution or comparison triggers the V1 rule;
- equivalent presentations produce different obligations or quotient classes;
- either universal direction lacks a unit, counit, triangle identity,
  naturality square, or substitution-stability proof;
- one direction is inferred from the other without a theorem;
- a contextual response cannot derive or include both `G-Use` and
  `G-Compute`;
- free sealing adds an undemanded generator or equation;
- a verifier-only ambient construction is counted as public payment;
- an already-public completion is resealed instead of expiring as `Derived`;
- a one-sided-only generic case is silently accepted as two-sided;
- generic behavior depends on an enumeration order or deterministic
  presentation key;
- the full cone is reduced by ranking; or
- any archived result or later interpretation influences the trigger,
  grammar, quotient, or acceptance rule.

Evidence that the generic trigger is normally trivial, that the two universal
directions are not jointly available in the intended fragment, or that the
package cannot specialize to the local eliminator would falsify this version
even if a richer rule happened to lengthen the registered run.

## Current blockers to adoption

The repository does not yet provide:

- a finite universal context grammar and universal canonicity theorem;
- one common verified calculus identifying the current context and
  substitution representations;
- universal-property and exact-free-seal certificates for either polarity;
- natural-family and univalent presentation quotient completeness;
- total contextual specialization into the existing local completion ports;
  or
- an Agda implementation agreeing with Rust on the generic suite.

The existing Schema2 contextual-internality result is only term-level
specialization. It mints no family, orbit, or universal interface and cannot
discharge these blockers.

## Adoption gate

Before any registered-H3 contextual run:

1. independently review and either adopt or reject the two-sided motivation;
2. implement the generic trigger and anonymous universal interfaces;
3. close the context, quotient, specialization, and free-seal blockers;
4. obtain Rust/Agda agreement on every generic vector;
5. issue and review the complete semantic manifest; and
6. freeze its semantic digest before exposing it to the registered prefix.

Until then `gsc-contextual-internalization-v1` remains
`proposed_not_adopted`.
