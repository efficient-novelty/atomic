# Law V2 Lambda/Unit Production Refinement Adjudication V2

Status: additive theorem/protocol successor; not adopted; not frozen

Profile under refinement:

```text
gf2-semantic-audit-lambda-unit-v3
```

Predecessor adjudication:

## Decision

Exact Rust-Agda correspondence is mediated by one canonical wire bundle. Safe
Agda proves semantic soundness for every bundle accepted by its pure
decoder/checker. Rust independently parses, checks, kernel-replays, and
re-encodes the same bytes. Cross-language authority requires:

1. exact canonical bundle-byte round-trip;
2. proof that the generated Agda input contains those exact bytes;
3. safe-Agda acceptance of those bytes;
4. independent Rust replay of those bytes; and
5. exact equality of the normalized transcript bytes emitted by both sides.

A digest comparison alone is insufficient at every byte-equality boundary.
Digests may record the result only after the actual bytes have been compared.

This adjudication is a theorem/protocol successor for the unchanged V3
profile. It is not a semantic V4. It changes neither the lambda/unit family
calculus nor the authority order. It does not create a native carrier, a
rewrite system, a Profile A adapter, or any live `kappa` or `nu`.

The production-refinement V1 adjudication and prototype result remain valid.
This V2 adjudication narrows their four correspondence blockers to one
common-byte checker architecture.

## Trust boundary

The authority claim, if the complete protocol is eventually implemented, is:

> Safe Agda proves the semantics of the canonical production bundle. Rust
> independently verifies and kernel-replays the same bundle and emits the
> same normalized transcript.

Rust is an untrusted certificate producer and an independently checked replay
implementation. Certificate-producing Rust algorithms may be wrong without
invalidating the semantic theorem: a wrong producer must fail either the
canonical checker, safe-Agda checker, Rust replay, or transcript comparison.

This architecture does not formally verify:

- the Rust compiler;
- the Rust language semantics;
- arbitrary compiled Rust programs;
- the operating system or hardware; or
- an extensional correspondence between all Rust and Agda values.

It proves the soundness of a small accepted-certificate language over exact
bytes. Similar constructor names, separately successful checks, matching
digests, expected outputs generated by Rust, or line-by-line inspection are
not cross-language proof authority.

The safe-Agda proof checker is the semantic authority for accepted bundles.
Rust supplies independent replay evidence and a common transcript; Rust does
not supply Agda theorem constructors or expected answers.

## Authority exclusions

This lane is generic-only. It may consume only verifier-produced generic

Success in this lane is not:

## Canonical wire

The authoritative format belongs in the isolated nested workspace:

```text
crates/pen-production-wire
```

The protected `pen-kernel` source is unchanged.

Serde and JSON may remain authority-free adapters, but they are not the
cross-language wire. The manual canonical wire uses:

- one-byte tags;
- little-endian `u16`, `u32`, and `u64`;
- `u64` length-prefixed byte strings;
- `u64` length-prefixed sequences; and
- option tags `0` and `1` only.

The top-level framing is:

```text
magic
schema-version
section-count
repeated {
    section-tag
    section-length
    section-payload
}
```

The magic and schema version make the otherwise schema-dependent canonical
encoding self-identifying.

The canonical decoder rejects:

- incorrect magic or version;
- unknown section or value tags;
- missing, extra, reordered where order is fixed, or duplicate sections;
- noncanonical length or option encodings;
- arithmetic or allocation-bound overflow;
- out-of-range slots or variables;
- omitted or extra fields;
- truncated input; and
- trailing bytes.

Successful decoding is not yet authority. The decoder must re-encode the
decoded value and compare the actual result bytes with the input bytes.

## Wire terms and global slots

Raw `GlobalId` is a digest identity, not declaration-order evidence. Terms on
the common wire therefore use finite global slots:

```rust
enum WireTermV1 {
    Sort { level: u16 },
    Variable { index: u32 },
    GlobalSlot { slot: u32 },
    Pi {
        parameter: Box<WireTermV1>,
        body: Box<WireTermV1>,
    },
    Lambda {
        parameter: Box<WireTermV1>,
        body: Box<WireTermV1>,
    },
    Apply {
        function: Box<WireTermV1>,
        argument: Box<WireTermV1>,
    },
    UnitType,
    Unit,
}
```

The signature carries the identity mapping separately:

```rust
struct GlobalSlotEntryWireV1 {
    slot: u32,
    global_id_bytes: [u8; 32],
    declaration_type: WireTermV1,
    declaration_body: Option<WireTermV1>,
}
```

The semantic-side Rust builder must derive this exact ordered table from a
`VerifiedSignature` and its matching `VerifiedGlobalSlotTableV1`. A caller
may not supply or reorder entries. The builder must check that:

- both capabilities bind the same verified-signature digest;
- slots are exactly `0..m-1`;
- each slot's 32 identity bytes equal the exact verified `GlobalId`;
- declaration type and optional body equal the verified declaration;
- each declaration refers only to earlier slots; and
- translating the wire table back reproduces the exact verified table.

The authority-free wire crate parses bytes but does not mint this semantic
binding.

Agda treats the 32-byte identity as opaque data. It need not implement the
Rust digest algorithm. Rust proves:

```text
verified Rust GlobalId <-> verified wire slot
```

and safe Agda proves:

```text
accepted wire slot <-> Agda Fin global-count
```

Only their composition establishes the global correspondence.

## Context representation and universe boundary

A wire context is stored oldest first:

```rust
struct ProductionContextWireV1 {
    entries_oldest_first: Vec<WireTermV1>,
}
```

Safe Agda decodes it to:

```agda
Σ Nat λ local-count →
  PCtx global-count local-count
```

For each variable index it checks and proves:

```text
index < context-length
oldest-first-ordinal = context-length - 1 - index
shift-distance = index + 1
```

The decoder, not the producer, recomputes the ordinal and shift distance.
Any diagnostic claims carried on the wire must match the recomputed values.

The universe split is:

```text
public term levels:           {0, 1}
checker-produced term levels: {0, 1, 2}
formation witness levels:     {0, 1, 2, 3}
```

Formation witness levels are numeric proof metadata, not public term syntax.
A checker-produced `Sort(2)` may require a formation witness at level `3`;
this never admits `Sort(3)` as a public or checker-produced wire term.

## Safe Agda decoder and checker

The safe package is structured around pure functions:

```agda
decodeBundle :
  List Byte →
  Maybe ProductionRefinementBundleV1

checkBundle :
  (bundle : ProductionRefinementBundleV1) →
  Dec (AcceptedProductionBundleV1 bundle)
```

The accepted record contains four dependent proof fields:

```agda
record AcceptedProductionBundleV1
  (bundle : ProductionRefinementBundleV1) : Set₁ where
  field
    context-and-global-correspondence :
      ContextAndGlobalCorrespondence bundle

    base-conversion-correspondence :
      BaseConversionCorrespondence bundle

    synthesis-correspondence :
      SynthesisCodeCorrespondence bundle

    inventory-and-family-correspondence :
      InventoryAndFamilyCorrespondence bundle
```

The checker is generic. It proves the meaning of every bundle that it accepts;
it is not a finite table of expected results.

The canonical codec target is:

```agda
decodeBundle (encodeBundle bundle) ≡ just bundle
```

Encoding injectivity follows:

```text
encodeBundle(x) = encodeBundle(y)  ==>  x = y
```

This is the semantic role of exact same bytes.

No Agda `postulate`, unsafe option, generated theorem body, or
Rust-manufactured proof constructor may inhabit the accepted record.

## Exact Agda input transport

The generated Agda input module contains exactly one varying object:

```agda
inputBytes : List Byte
inputBytes = ...
```

An exact hexadecimal string is also acceptable if the parser and source
template are fixed, but byte-list and hexadecimal modes may not be mixed
implicitly.

The generated source may not contain:

- expected decoded terms or contexts;
- expected inferred types or formation levels;
- expected transcripts or digests;
- theorem bodies;
- Rust-produced proof constructors; or
- expected success Booleans.

Before Agda runs, a host-side verifier extracts the bytes from the exact fixed
source template, re-renders the source, and compares the extracted actual
bytes with the canonical `.wire` artifact. A successful transport capability
proves only this equality. It is strictly weaker than safe-Agda bundle
acceptance.

The generated module then asks Agda to compute decoding and checking. It does
not tell Agda what answer to obtain.

## Finite context and global correspondence

The first accepted-bundle proof checks:

- exact global-slot coverage `0..m-1`;
- uniqueness of every 32-byte global identity;
- exact declaration types and optional bodies;
- strict-prior references in declaration types and bodies;
- absence of forward or out-of-range globals;
- scoped decoding of every `PGlobal` and `PVar`;
- newest-first variable lookup in oldest-first contexts;
- context extension;
- weakening and shift;
- simultaneous substitution and binder lifting; and
- structural encode/decode round trips.

The future Rust capability records the canonical bundle and verified table
identities plus the exact Agda and Rust evidence. It may be minted only from
safe-Agda acceptance of the exact bundle bytes and exact Rust round-trip.

## Combined conversion and synthesis checker

Base conversion and synthesis are checked together because application
synthesis consumes conversions, while nested conversion congruence can
require local synthesis evidence.

Synthesis protocol V2 is unchanged. Additional binder-local evidence belongs
to this bridge:

```rust
struct ConversionTypingSupplementWireV1 {
    conversion_id: WireId,
    step_path: Vec<u32>,

    local_context: ProductionContextWireV1,
    local_endpoint_judgment: EndpointJudgmentWireV1,

    source_typing_code: SynthesisCertificateWireV1,
    target_typing_code: SynthesisCertificateWireV1,

    formation_level: Option<u16>,
}
```

For every nested congruence premise both checkers:

1. derive the required binder-local context from the enclosing source and
   target;
2. compare it with the supplied local context;
3. verify source and target typing/synthesis codes;
4. require the exact local endpoint judgment;
5. independently replay both sides through the unchanged Rust kernel; and
6. decode and prove the same local evidence in safe Agda.

Outer-context shift approximation is forbidden.

### Conversion

The safe checker decodes beta, authorized transparent delta, and congruence
steps into typed reduction evidence. Both traces must replay to one exact
common normal form.

For transparent delta it combines:

- the exact wire global slot;
- the exact bodyful slot-indexed declaration;
- the verified predecessor-public delta-policy binding transported to V3;
  and
- the safe-Agda typing proof for that decoded delta step.

For `TypeFormation`, Agda computes an existential numeric formation level:

```agda
Σ Nat λ level →
  Σ ⊢ Γ ∶ term ∶ sort level
```

The level is emitted in the normalized transcript. It is not trusted merely
because the producer serialized it.

Both checkers recompute the complete no-applicable-redex census. A
producer-supplied census with the expected length is insufficient.

### Synthesis

The combined checker verifies the exact payload of:

```text
Sort
UnitType
Unit
VariableLookup
GlobalLookup
PiFormation
LambdaIntroduction
ApplicationElimination
```

For variable lookup it recomputes the selected ordinal, shift distance, and
shifted type. For global lookup it resolves the finite slot in the exact
signature.

For application elimination it:

1. checks the function subcode;
2. checks conversion of the function type to a `Pi`;
3. checks the argument subcode;
4. checks conversion of the argument to the parameter;
5. computes dependent result substitution;
6. compares the computed result with the wire result; and
7. constructs the abstract conversion-aware application derivation.

The generic theorem target is:

```agda
synthesis-checker-sound :
  checkSynthesis bundle code ≡ yes checked →
  AbstractConversionTyping
    (decodeTerm (subject checked))
    (decodeTerm (inferredType checked))
```

## Canonical normalized transcript

Rust and Agda independently compute a versioned canonical transcript from the
same canonical bundle. The transcript contains:

- decoded signature and contexts;
- variable and global resolutions;
- inferred types;
- numeric formation levels;
- every conversion step and endpoint;
- binder-local conversion supplements;
- common normal forms and no-redex censuses;
- synthesis rule trees, premise identifiers, and conversion identifiers;
- dependent application result types;
- Q0 mappings;
- fresh-rule dispositions; and
- family payload mappings.

The transcript has its own explicit schema identity. It may reuse the
canonical primitive codec, but it is not an unversioned concatenation of
diagnostic strings or checker stdout.

The factory compares:

```text
canonical-bundle bytes
  = bytes extracted from the Agda input artifact
  = bytes independently replayed by Rust

Agda canonical-transcript bytes
  = Rust canonical-transcript bytes
```

Only after each actual byte comparison succeeds may it record bundle and
transcript digests.

## Generic soundness and carrier completeness are separate

An accepted-bundle checker proves:

```text
every accepted certificate has the stated abstract meaning
```

It does not prove:

```text
this finite bundle contains every root required by the native V3 carrier
```

Carrier-derived completeness remains downstream. After production refinement
is minted:

1. construct the native V3 rank-0/1/2 carrier;
2. derive the authoritative root set from that carrier;
3. create one subject bundle containing all required roots and reducts;
4. prove exact set equality between bundle roots and carrier-required roots;
5. run the generic accepted-bundle checker; and
6. mint `VerifiedCarrierDerivedTypingSubjectCoverageV1`.

A caller-provided or selected root slice, even a large or empty one, cannot
establish completeness.
