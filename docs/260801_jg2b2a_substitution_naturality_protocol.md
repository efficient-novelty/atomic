## P0 entry audit

The JG2b2 entry audit found a theorem-specification gap, not an implementation
detail. The book requires a capability to be natural under every admissible
substitution in its public context. The previous plan instead asked for a
finite admissible-substitution universe without defining its members, its
source and target contexts, its equality, or why a finite collection could
establish the universal statement.

The discharged JG2a grammar is intentionally weaker than the missing theorem:

- its nine interface sorts are target-neutral operational sorts, not kernel
  terms;
- its seven schemas describe kinds of reusable operation, not executable
  realizations or reindexing actions;
- it fixes `constructor -> role` but does not derive
  `public occurrence -> constructor`; and
- one `VerifiedClosedSpecialization` replays one closed assignment only.

The current kernel likewise exposes no proof that an arbitrary typed
simultaneous substitution preserves typing, normalization, or a constructor's
naturality square. Finite samples, selected generators, repeated closed
specializations, and successful example squares therefore cannot mint
universal naturality. This is the same separation already recorded by the
project: finite derivation-local witnesses and unbounded algebraic laws require
different authorities.

JG2b2a resolves only the protocol ontology. It freezes what later executable
and factual authorities must mean and forbids every shortcut exposed by the
audit. It does not pretend that those later theorems already exist.

## Book-level theorem target

The following is the theorem schema that combined JG2b2b must make executable
and freeze canonically, culminating only at JG2b2b3c. JG2b2a binds the rule
requiring that later schema; its
grammar token does not itself encode the substitution orientation, the
reindexing actions, the equality, or these equation endpoints.

Fix a verified sealed boundary `Sigma`, verified dependent public contexts
`Gamma` and `Delta`, and a kernel-typed simultaneous substitution

```text
theta : Delta => Gamma.
```

The substitution contains one complete image for every declaration of
`Gamma`, stored oldest declaration first. Images are checked sequentially, so
for `Gamma = (A_0, ..., A_{n-1})`:

```text
Sigma; Delta |- theta_i : A_i[theta_0, ..., theta_(i-1)].
```

For a frozen constructor `c`, with an input tuple `x` in context `Gamma`, let
`In_c(theta)` and `Out_c(theta)` be the exact reindexing actions fixed for its
input and output interface sorts. For every kernel-admissible `Delta` and
`theta : Delta => Gamma`, universal naturality is the equation

```text
nf(Out_c(theta)(c_Gamma(x)))
    =
nf(c_Delta(In_c(theta)(x)))
```

This is a formal theorem subject for one constructor schema, not a claim that
any factual structural occurrence realizes `c`. Later JG2b2c must classify
each internally derived `(occurrence, constructor)` pair and may obtain a
unique match, zero matches, or typed ambiguity.

Equality is the executable typed equality fixed for the output sort. It is not
equality of caller digests, labels, or cached Boolean results.

The equation has one required instance for each frozen constructor:
`Formation`, `Abstraction`, `Aggregation`, `Transport`, `Comparison`,
`DemandCompiler`, and `DischargeTransformer`. In particular, the two
substitution-consuming constructors require an explicit composition or
whiskering action; schematic resemblance to transport is not a naturality
proof.
