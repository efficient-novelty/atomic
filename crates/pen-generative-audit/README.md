# `pen-generative-audit`

This isolated crate begins mandatory Phase JG without modifying or reusing the
semantic-audit carrier, its four semantic roles, or its negative SR2 theorem.

The implemented JG1 authority freezes exactly:

- seven generative-capability roles;
- eight admission obligations; and
- two receipt-source forms.

The receipt-source grammar is

```text
(NewPaidClause × GenerativeCapabilityRole)
  ⊔ PriorLiveGenerativeRequirementOutput
```

so the second summand is deliberately not multiplied by the role vocabulary.
If later JG stages certify a marginal capability set and an injective receipt
assignment, the resulting counting shape will be

```text
|GCapMarg| ≤ 7 |K| + |GenReq|.
```

Only a separate exact cost theorem may replace `|K|` by `kappa`.

`VerifiedGenerativeCapabilityConstructorGrammarV1` binds seven disjoint
finite interface shapes to the opaque JG1 token. Constructor shape is the only
source of its frozen role; callers cannot supply a role choice. JG2a does not
yet classify a public occurrence into a constructor. JG2b2b2a-A3-O freezes one
deterministic checked realization/classifier predicate, principal-root
selector, and formal naturality subject per ordered constructor over the
frozen A2-O substrate. The A4-O RC1 release audit showed that the selectable
  ordinary definition is not yet closed; the remaining chain
  `R2d(QG2 -> QG3 -> roots/runtime) -> R3 -> R2e -> R4` must close it before
JG2b2b2b may implement the executable grammar and particular operations. One schema per constructor proves neither totality
nor disjointness and classifies no occurrence: JG2b2b3c must finish the
universal theorem package, and JG2b2c must derive the complete pairwise matrix
and aggregate unique/zero/typed-ambiguity result rather than accept a caller
constructor tag.

`VerifiedGenerativeCapabilityStageSurfaceV1` requires a nonempty candidate,
the combined grammar-bound `FreeSealingFragment` scope, an exact verified
predecessor, and an opaque free-sealing capability. It independently replays
the extension through `pen-kernel`, compares the complete normalized
successor, and retains the verified predecessor, replay-derived normalized
candidate, and successor for JG2b.

`VerifiedContiguousGenerativeStageChainV1` starts at an internally verified
empty signature, requires exact stage adjacency, replays every normalized
extension, separates normalized transition IDs from history-relative event
IDs, and derives one birth record for every terminal declaration. Its
normalized identity excludes arbitrary trusted-scope fields and exact raw
candidate syntax; a separate evidence digest binds the ordered exact JG2a
manifests.

JG2b1a resource policy V1 is explicitly relative to the bound kernel
configuration: stage count is limited by `max_depth`, retained/terminal
declarations by `max_operations`, and aggregate inspected declaration material
by the checked V1 formula. Exact token equality includes exact evidence
provenance; `same_normalized_chain_as` and `normalized_chain_digest` provide
scope/raw-syntax-neutral normalized comparison.

JG2b1a alone is a relative-chain authority, not a complete-through-head
authority. A valid tail truncation remains a valid shorter chain, and valid
split and coalesced
segmentations remain distinct chains. JG2b1b2 now consumes the opaque closed
event evidence by value, honors the frozen segmentation rule, and independently
replays the producer-finalized branch head before minting completeness through
that head. Caller transcripts, frame slices, counts, boundaries, digests, and
EOF flags are not substitutes. The protocol never claims a globally latest
branch or a global EOF.

`OpenGenerativeSealedLogV1` is deliberately non-cloneable and process-local.
Each successful append internally verifies one JG2a stage and commits one
frame. `close_generative_sealed_log_v1` consumes the writer and produces an
opaque, non-cloneable `ClosedGenerativeSealedLogV1`; it does not independently
replay the snapshot and therefore carries no completeness-through-head
authority. Its distinct producer-finalized-head commitment is minted only by
consuming close; the rolling exact append-state head visible while open is not
that finalized commitment. An
internally allocated checked atomic branch identity separates exact parallel
branches, while identical normalized transitions retain identical normalized
log-head identity. The branch identity has no persistence or cross-process
meaning. Resource exhaustion never closes a writer and never establishes a
finalized head or global EOF.

## Authority boundary

`VerifiedPreExposureGenerativeCapabilityGrammarV1` certifies only the exact
JG1 vocabulary, ordering, canonical bytes, and deterministic digest. The two
JG2a tokens certify only the finite constructor grammar and one exact public
stage boundary. JG2b1a additionally certifies replay, adjacency, and terminal
birth coverage relative to a supplied chain. JG2b1b2 certifies branch-relative
completeness through its exact producer-finalized head. JG2b2a certifies only
the exact substitution/naturality protocol grammar and verifier profile.
JG2b2b0 certifies only the closed structural occurrence grammar and identity
vocabularies; because it takes no history, it certifies no occurrence. JG2b2b1
certifies only exact retained substitution and reindexing instances that have
completed local construction and kernel replay. None of these authorities
certify a realized constructor, a generic substitution law, universal
naturality, a globally
latest branch, global EOF, complete support, capability instance,
native carrier, quotient, weakening map, marginal, strict enlargement,
provenance injection, `gamma`, bootstrap value, candidate acceptance, debt, or
selection result.

The crate accepts no registered Genesis prefix, held-out label, oracle output,
caller-defined role, caller capability list, or obligation Boolean. A trusted
scope's supplied `history_digest` remains a binding field, not proof of a
verified history. Full JG2 remains open at the active A4-R2d QG2-O2b operation-
role cut within combined
JG2b2b, after the non-authority JG2b2b2-P0/JG2b2b2a-A0 audits, the A1
